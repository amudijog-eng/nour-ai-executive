# نظام واتساب وسكرتيرة الذكاء الاصطناعي (Meta Cloud API)

نظام متكامل واحترافي يربط **Meta WhatsApp Cloud API** برقم هاتفك مع واجهة ويب تفاعلية وسكرتيرة ذكية (AI Secretary Agent) للرد التلقائي، تنظيم المواعيد، وتلخيص طلبات العملاء.

---

## 🌟 المميزات الرئيسية
1. **لوحة تحكم تفاعلية فورية (Live Web Dashboard):**
   - متابعة المحادثات في الوقت الفعلي عبر تقنية WebSockets (Socket.io).
   - إرسال واستقبال الرسائل يدوياً أو آلياً.
   - صندوق وارد متكامل مع جهات الاتصال وعداد الرسائل غير المقروءة.
2. **سكرتيرة ذكية (AI Agent - "نور"):**
   - ردود لبقة واحترافية تناسب بيئة الأعمال الأردنية والعربية.
   - التعرف التلقائي على طلبات المواعيد والاجتماعات والاستفسارات الهامة.
   - استخراج وتلخيص المواعيد وحفظها في بطاقات منظمة في لوحة التحكم.
   - زر تحكم فردي لتفعيل أو إيقاف السكرتيرة لكل محادثة على حدة.
   - دعم كامل لمحرك **Google Gemini** أو **OpenAI** (مع ردود ذكية مدمجة حتى لو لم يتوفر مفتاح API).
3. **قاعدة بيانات محلية مدمجة (SQLite):**
   - حفظ دائم وآمن للمحادثات وجهات الاتصال والملاحظات بدون أي إعدادات معقدة.
4. **محاكي رسائل مدمج (Quick Simulator):**
   - تجربة واستعراض النظام ورد السكرتيرة بضغطة زر واحدة دون الحاجة لانتظار إعدادات ميتا.

---

## 🚀 طريقة التشغيل السريع

### 1. تشغيل السيرفر
افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع ونفّذ:
```bash
npm start
```
سيعمل السيرفر فوراً على الرابط:
👉 **`http://localhost:3000`**

---

## 🔗 ربط السيرفر مع Meta WhatsApp Cloud API

### الخطوة 1: فتح نفق عام مجاني للـ Localhost (Tunnel)
تحتاج سيرفرات Meta لرابط عام `HTTPS` لإرسال الرسائل الواردة. يمكنك استخدام **Cloudflare Tunnel** المجاني بدون تسجيل وبأمر واحد:
```bash
npx cloudflared tunnel --url http://localhost:3000
```
*(أو باستخدام `npx ngrok http 3000`)*.
انسخ الرابط الذي يظهر لك، مثلاً: `https://xxxx.trycloudflare.com`.

---

### الخطوة 2: إعداد الـ Webhook في Meta for Developers
1. ادخل إلى [Meta for Developers](https://developers.facebook.com) وسجّل الدخول.
2. ادخل إلى تطبيقك > من القائمة الجانبية اختر **WhatsApp** > ثم **Configuration**.
3. في قسم **Webhook** اضغط **Edit**:
   - **Callback URL:** ضع رابط النفق متبوعاً بـ `/webhook`:
     `https://xxxx.trycloudflare.com/webhook`
   - **Verify token:** ضع الرمز السري التالي:
     `whatsapp_secret_agent_2026`
4. اضغط **Verify and Save**.
5. بعد الحفظ، اضغط على **Manage Webhook fields** وفعّل خيار **`messages`** بالضغط على **Subscribe**.

---

### الخطوة 3: ربط الرقم الأردني
1. في لوحة Meta for Developers > اذهب إلى **WhatsApp** > **API Setup**.
2. ستجد زر **Add phone number** (إضافة رقم هاتف).
3. أدخل اسم نشاطك التجاري، ثم أدخل **الرقم الأردني** المخصص للخدمة (`+96279...`).
4. اختر استلام رمز التحقق عبر **رسالة نصية SMS**.
5. أدخل الرمز الذي يصلك لتأكيد ملكية الرقم.
6. انسخ **Phone Number ID** الخاص برقمك وضعه في صفحة إعدادات الداشبورد (`http://localhost:3000`).
7. انسخ **Access Token** وضعه أيضاً في إعدادات الداشبورد.

---

## 🤖 ضبط وتخصيص السكرتيرة الذكية
- افتح واجهة الويب واضغط على أيقونة **الإعدادات والربط**.
- يمكنك تعديل شخصية السكرتيرة، اسمها، أو أسلوب كلامها عبر خانة (System Prompt).
- يمكنك وضع مفتاح **Gemini API Key** المجاني من [Google AI Studio](https://aistudio.google.com/) لتحصل السكرتيرة على ذكاء فائق في إدارة الحوار وفهم كافة التفاصيل.
